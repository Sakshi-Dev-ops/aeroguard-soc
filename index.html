📖 Quick How-to-Play Tutorial

If you're new to coding or cybersecurity, don't worry! Here is how to run through the simulation step-by-step:
Step 1: Hit "Launch Cyber Attack" on the radar screen to simulate an incoming flight breach.
Step 2: Click on any satellite button that turns RED on the radar view.
Step 3: Read the top comment line (`// BUG: ...`) in the code editor to see what's wrong.
Step 4: Edit the mistake in the box and click "Deploy Security Patch" to save the satellite!

What problem does this solve?

A lot of people want to learn about cybersecurity, but reading about code errors in a textbook gets boring fast and doesn't really show you how bugs work in real life. Most beginner coding games are either too simple or way too complicated to follow. We built this project to give users a fun, hands-on way to test out real JavaScript code fixes on moving satellite targets so anyone can practice basic coding logic without getting lost.

How it connects to aerospace defense ("Into the Skies"):

Satellites and high-altitude drones rely on radio signals to stay on course. If someone tampers with those signal checks or overloads the drone's memory buffer, the aircraft can lose control. In our simulation, you act as a ground security operator who catches these corrupted code lines and fixes them before the flight system fails.

Code Patch Example:

Broken Code (Bug):
function validate(packet) {
  if (packet.verifyCRC == false) {
    return ACCEPT_DATA;
  }
}
Your Fix (Patched):
function validate(packet) {
  if (packet.verifyCRC == true) {
    return ACCEPT_DATA;
  }
}
